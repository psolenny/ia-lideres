# IA para líderes · CECOMSA

Suite del workshop «IA para líderes: menos tareas, más resultados» del Modelo de Liderazgo CECOMSA.
Sitio estático para GitHub Pages; no requiere compilación.

## Páginas

| Archivo | Contenido |
| --- | --- |
| `index.html` | Inicio: fechas, cómo funciona, accesos |
| `dia-1.html`, `dia-2.html` | Presentaciones (← → espacio · `f` pantalla completa · `o` índice) |
| `kit-general.html`, `kit-dia-1.html`, `kit-dia-2.html` | Kits para participantes |
| `buenas-practicas.html`, `prompts.html` | Guías para después del taller |
| `politica-ia.html` | Resumen de la política de uso de IA de CECOMSA |
| `rubrica.html` | Rúbrica del pitch final |
| `equipos.html`, `resultados.html` | Memoria del taller y tablero de horas liberadas |
| `imprimir.html` | Guía de bolsillo, ficha del reto y registro en tamaño carta |

## Actualizar equipos y resultados

Editar `assets/datos.js` después de cada sesión. El repositorio es público: usar nombre de equipo y área, **no nombres de personas**.

## Marca

Colores exactos del Manual de Identidad (azul `#002F6C`, magenta `#A20067`, verde `#84BD00`, naranja `#FF6900`, fucsia `#E31C79`).
Azul y verde solo en zonas de énfasis (portadas, tesis, separadores, cierres); el resto en blanco con los demás colores como acento.
Los logos de `assets/` provienen de los archivos oficiales usados en `innova-slides`; no se generan ni se modifican.

## Fuera de este repositorio

La guía del facilitador y los casos internos se guardan solo en local y no se publican.
